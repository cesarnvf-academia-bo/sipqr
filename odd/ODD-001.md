# ODD-001: Inicialización y arquitectura base del sistema

**Proyecto:** Sistema de Información de Pagos QR (SIPQR)  
**Metodología:** Organic Driven Development (ODD)  
**Prioridad:** Alta  
**Dependencias:** Ninguna

---

## 1. Objetivo

Construir la estructura inicial de un sistema de información web utilizando PostgreSQL 18, Java 25, Spring Boot 4.1.x, MyBatis XML, Angular 22, TypeScript 6 y Tailwind CSS 4.

Establecer a arquitectura modular, escalable, mantible y segura que permita implementar progresivamente las funcionalidades del sistema mediante objetivos ODD independientes.

Toda la implementación deberá utilizar convenciones en español, sangría de cuatro espacios, buenas prácticas de programación y separación de responsabilidades.

El proyecto deberá quedar preparado para su ejecución en a un entorno local de desarrollo.

## 2. Contexto

El proyecto comienza desde cero y se desarrollará utilizando OpenCode como agente de programación.

### 2.1. Tecnologías obligatorias

| Componente | Tecnología |
|---|---|
| Base de datos | PostgreSQL 18 |
| Lenguaje backend | Java 25 |
| Framework backend | Spring Boot 4.1.x |
| Persistencia | MyBatis con XML |
| Seguridad | Spring Security + JWT |
| Documentación API | OpenAPI / Swagger UI |
| Lenguaje frontend | TypeTypeScript 6 |
| Framework frontend | Angular 22 |
| Estilos | Tailwind CSS 4 |
| Arquitectura frontend | Componentes reutilizables y heredados |
| Gestor de paquetes | npm |
| Sistema operativo de desarrollo | Linux |

### 2.2. Modificaciones acordadas

- La parte lógica utilizará un estilo de arquitectura por capas (modelo, repositorio, servicio, controlador y configuración).
- La base de datos será `sipprbd`, con usuario `postgres` y clave `123qwe`.
